Somos mais que uma guilda. Somos uma família forjada nas batalhas de Ernas. Em GrandChase Classic, buscamos a glória, mas valorizamos a honra, a amizade e o espírito de equipe acima de tudo.

Observação Importante

Para aqueles que desejam utilizar os sistemas de controle, é necessário observar que todo sistema possui uma proteção de Auto Save (memória cache do navegador). Contudo, para garantir a segurança absoluta de seus dados, é indispensável clicar no botão Salvar.

Para acessar novamente esses dados em outro momento ou dispositivo, basta utilizar o botão Carregar e selecionar o arquivo salvo anteriormente.

Na página de FARM, o sistema opera com um relógio interno sincronizado, realizando o Reset Automático das missões exatamente às 03:00 AM (Horário de Brasília).
